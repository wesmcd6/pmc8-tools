# ExploreStars Envision&trade; — Windows Desktop

Native Windows desktop app for controlling Explore Scientific&trade; PMC-Eight&trade; telescope mounts.

## Download

📦 **[Get the latest Windows zip from the Releases page →](../../releases/latest)**

Look for the asset named:

> `ExploreStars-Envision-vX.Y.Z.W-windows.zip`

The Releases page also keeps every prior version available, so if you need a specific older build you can pick it from the [release list](../../releases).

> **Note:** This branch used to ship a copy of the Windows zip directly. As of v2.1.0.2 it's a thin pointer — binaries live on the GitHub Releases page where versioning, changelogs, download counts, and historical builds are handled natively.

## Requirements

- Windows 10 (version 1903 / build 19041) or later
- Windows 11 supported

## Install

1. Download and extract the zip — you'll get an `ExploreStars-Envision/` folder
2. Run `ExplorestarsLite.Maui.exe` from inside that folder
3. Optionally pin to taskbar or create a desktop shortcut

> **Why is the executable still named `ExplorestarsLite.Maui.exe`?**
> The .NET project filename is unchanged from the rebrand to keep the
> upgrade path clean. The product name and all user-visible text are
> ExploreStars Envision&trade;.

## Connection

Connect to your PMC-Eight via Wi-Fi or Serial (USB / Bluetooth virtual COM port).
